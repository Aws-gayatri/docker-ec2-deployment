# Docker + AWS EC2 Deployment

This project demonstrates basic Docker deployment on an AWS EC2 Ubuntu instance.

## Steps Performed
* Created AWS EC2 Ubuntu instance
* Connected using SSH (MobaXterm)
* Installed Docker
* Verified Docker installation
* Ran Hello-World container
* Deployed Nginx container using Docker
* Accessed application through browser using EC2 Public IP

## Technologies Used

* AWS EC2
* Ubuntu Linux
* Docker
* MobaXterm

## Output

Docker container deployed successfully on AWS EC2.
